# 水下机器人实验（underwater-robot-experiment）

水下机器人（ROV）自主寻找并轻触红球。Mac 通过网线直连机器人（不经树莓派）。
GitHub 仓库名受英文限制，中文名即「水下机器人实验」。

## 快速开始

```bash
cd ~/rov-local-test
source .venv/bin/activate
python main.py
```

**所有操作都从 `main.py` 的数字菜单进入**，不需要记任何命令行参数：

```
  1. 视频测试        看画面、测帧率（不发指令）
  2. 颜色标定        调 HSV 阈值（不发指令）
  3. 检测验证        看检测框效果（不发指令）
  4. 手动控制        WASD 驾驶 · 自动检测 · P 拍照
  5. 自主模式        自动找球→对准→碰触
  6. 系统检查        测试视频/通信连接
  7. 关闭机器人      发送关机指令
  0. 退出
```

默认**模拟模式**（不发推进器指令，只在屏幕上显示将要发送的内容）。
进入模式 4/5 时询问是否连接真实机器人，输入 `y` 才会输出真实指令。

## 按键表

### 4. 手动控制（WASD 驾驶 + 自动检测）

| 按键 | 功能 |
|------|------|
| `W` / `S` | 前进 / 后退 |
| `A` / `D` | 左转 / 右转 |
| `R` / `F` | 上浮 / 下潜 |
| `1` / `2` / `3` | 速度档（慢 0.5 / 中 0.75 / 快 1.0）|
| `P` | **保存当前图像**（存 `snapshots/`，原图可直接用于标定）|
| `空格` | 立即停桨 |
| `T` | 检测框开关（默认开）|
| `Q` / `ESC` | 退出（自动发停桨帧）|

> **松键自动回停**：按住生效，松开约 0.5 秒自动回停桨——手一松机器人就停。

### 5. 自主模式

| 按键 | 功能 |
|------|------|
| `空格` | 暂停 / 恢复（暂停时发停桨帧）|
| `R` | 重新开始任务 |
| `T` | 检测框开关 |
| `-` / `=` | **力度减 / 加**（0.5×–1.5×，推力整体缩放，游不动就加）|
| `Q` / `ESC` | 退出（自动发停桨帧）|

### 3. 检测验证 / 2. 颜色标定

- 检测验证：`T` 掩膜叠加、`P` 保存图像、`Q`/`ESC` 返回
- 颜色标定（color_tune）：`w/s e/d r/f t/g y/h u/j` 调 HSV 六个边界，`1/2` 粗/细调，`p` 打印阈值，`b/n` 切红/绿，`z` 重置，`q` 退出

## 自主状态机

```
SEARCH（直行前进找球）──检出──▶ ALIGN（转向对准画面中央）
                                    │ 对中
                                    ▼
BACKOFF（后退 1.5s）◀──TOUCH（轻推 1.5s）◀── APPROACH（前进接近）
      │
      ▼
   DONE（停桨，任务结束）
```

- **寻找策略**（长方形水池，球扔在对侧贴墙处）：直行找球 → 到墙没见到球 → **持续后退离墙 → 小角度转（25° 逐次递增）停下观察 → 小步挪动**（同侧看满 3 次掉头看另一侧，来回直到发现球）
- **航向保持**：用姿态传感器 yaw 记住出发航向，直行防跑偏；无姿态数据时用左右走廊视觉居中修正
- **蓝墙避障**：前方走廊蓝色占比 ≥30% 且没看到球时处理（目标可见时直接冲目标——球贴墙也能碰到）；**每帧都查**：任何搜索阶段前方出现墙都立即后退，墙没退开一直退；直行超 30 秒没见球也兜底后退换方向
- 丢失 > 0.8 秒回 SEARCH（重新直行）；目标太小（低置信）只对中不前进，防止在浑水误检上撞上去
- 状态大字显示在画面下方，终端只在状态切换时打一行

## 机器人协议要点

| 项 | 值 |
|----|----|
| 机器人主机 | `192.168.137.100`（Mac 网线直连）|
| WebSocket | `ws://192.168.137.100:8000`（机器人是服务端，电脑是客户端）|
| 视频流 | `http://192.168.137.100:8080/?action=stream`（MJPEG）|
| 控制指令 | 5 段：`左推进器:右推进器:左上:右上:关机标志` |
| PWM 范围 | 1262–1662，中位（停桨）**1462** |
| 反桨布置 | 水平左右推进器推力相反：前进 = 左 1523 / 右 1401 |
| 关机标志 | `0` 正常，`1` 关机（发后约 30 秒断电，需手动复位）|
| 传感器回传 | `roll:pitch:yaw` |
| 心跳 | **必须持续发指令**（10 Hz），否则推进器鸣叫；程序自动保活 |

## 浑水红球检测参数

浑水中远处的球物理上看不见，此时正确行为是 **LOST**（靠搜索状态兜底）。

| 参数 | 值 | 说明 |
|------|----|------|
| 红球 HSV 主段 | H 0–27, S ≥135, V ≥55 | 按 3 张真实水下截图标定 |
| 红球 HSV wrap 段 | H 170–179 | 红色跨 0/180 边界，双段自动合并 |
| 凸包填充率 | ≥ 0.85 | 替代圆形度（球面有接缝，圆形度不可靠）|
| 宽高比 | ≤ 2.5 | — |
| 最小面积 | 300 px² | — |
| 蓝墙 HSV | H 90–130, S ≥50, V ≥60 | 避障用，与红球完全正交 |
| 避障阈值 | 前方走廊蓝色 ≥30% | 实测：正对墙 49%，开阔浑水 0%（0.40 偏高易漏判）|

调参工具：`2 颜色标定` 实时调；或 `python analyze_color.py snapshots/xxx.jpg red` 对保存的图自动分析。
调好后写回 `rov/config.py` 的 `HSV_RANGES`。

## 今晚实机测试流程

1. `python main.py` → **6 系统检查**：确认视频/通信可达
2. → **3 检测验证**：看检测框确认红球检出；不行 → **2 颜色标定** 微调
3. → **4 手动控制**：先默认模拟模式看 HUD 和自动检测效果（`P` 存几张图），
   再重启选真实连接，小幅 WASD 验证方向（随时空格停桨）
4. → **5 自主模式**：搜索 → 对准 → 接近 → 轻触 → 后退 演练
5. → **7 关闭机器人**：输入 `yes` 确认后发关机指令，约 30 秒后断电

## 安全须知

- 默认模拟模式；真实推进器输出必须显式确认，且保留物理急停方式
- 空格随时停桨；退出/异常自动发中位停桨帧
- 手动模式松键 0.5 秒自动回停
- 关机指令仅菜单 7 发送（需输入 `yes`）
- `server.py` 是本机 WebSocket **模拟服务器**（127.0.0.1:8000），不是真实控制程序
